O envio físico USB ainda não foi validado na impressora. Não marque etiquetas como impressas apenas pela simulação. A conexão experimental pelo navegador não substitui o teste do aplicativo Android.

**Ajuste experimental v0.9:** imagem centralizada com margem interna, uma copia solicitada por comando. Se a impressora continuar avancando outras 3 etiquetas, calibre o sensor GAP antes de repetir o teste. O envio USB nao comprova a impressao fisica.

A conexão USB será liberada somente após permissão do Android. Não é preciso Wi-Fi.

Backup dos projetos

Os dados ficam no armazenamento deste navegador. Faça cópias regularmente para evitar perda após limpeza dos dados ou troca do aparelho.

Instalação e uso

A versão Android usa armazenamento privado no dispositivo. Antes de desinstalar ou atualizar, exporte um backup. Os dados guardados anteriormente no navegador não são transferidos automaticamente para o APK.

No APK a conexão USB é experimental e precisa de teste real na Elgin L42 Pro Full. O processamento dos dois PDFs foi validado com o formato de documentos do projeto Valentina.
